# Hey, I'm Zelijah. 👋

**Software engineer · Founder & Lead Developer · Creative technologist**

I build software where **security, useful tools, and creative technology** meet.

I'm the founder and lead developer of [Majikah Solutions OPC](https://majikah.solutions), a Philippine post-quantum security and software company. My current work is centered on practical digital trust: cryptographic signing, identity, encryption, and developer infrastructure.

I enjoy working across the stack—from cryptographic libraries and APIs to desktop applications, interfaces, and the systems that bring a product to life.

## What I'm building

Most of my current engineering work lives in the [Majikah](https://github.com/Majikah) ecosystem.

| Project | What it does |
|---|---|
| **[Majik Signature](https://github.com/Majikah/majik-signature)** | Local-first signing and verification for files and digital content, using hybrid Ed25519 and ML-DSA-87 (FIPS 204) signatures. |
| **[Majik Key](https://github.com/Majikah/majik-key)** | A mnemonic-based cryptographic identity and key-management library, with classical and post-quantum key families. |
| **[Majik Key for Rust](https://github.com/Majikah/majik-key-rs)** | A native Rust implementation of the Majik Key account model. |
| **[Majik File](https://github.com/Majikah/majik-file)** | A platform-agnostic encrypted file format built around ML-KEM-768 and AES-256-GCM. |

The wider ecosystem also explores encrypted communication, digital identity, and practical business software. The [Majikah organization profile](https://github.com/Majikah) has the company overview and links to its projects, SDKs, and developer resources.

## How I work

I care about building software that is useful, understandable, and maintainable—not just technically impressive.

- **Security with clear boundaries.** I prefer standards-led engineering and honest explanations of what a system does and does not protect against.
- **Privacy and user control.** Local-first execution and minimal data collection are worth designing for from the beginning.
- **Developer experience.** Good APIs, strong types, clear documentation, and predictable behavior matter as much as the underlying implementation.
- **Practical architecture.** I like systems that solve a real problem without adding complexity for its own sake.
